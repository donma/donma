## Hi, I'm Donma

I write software, collect data, and build things when the existing tools are not quite right.

Most of my day-to-day work is C#/.NET, but I also spend a lot of time with HTML, JavaScript, JSON, Cloudflare, and whatever else a project needs. Some projects are useful tools; some are experiments that got a little bigger than expected.

A few things I have built:

- **[LunarData](https://github.com/donma/LunarData)** — a static lunar-calendar dataset covering 1970–2100.
- **[Taiwan Address JSON](https://github.com/donma/TaiwanAddressCityAreaRoadChineseEnglishJSON)** — address and road-name data for Taiwan.
- **[Zune Tiles Player](https://github.com/donma/zune-tiles-player)** — a small tribute to the Zune interface.
- **[CopilotClawD](https://github.com/donma/CopilotClawD)** — an experiment in controlling local coding tasks through Telegram.

## What I use

C# · .NET · ASP.NET Core · JavaScript · TypeScript · SQLite · Cloudflare · GitHub Actions

I like projects that are easy to run, easy to inspect, and useful after the demo is over.

## Currently working on
