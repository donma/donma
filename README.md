## About

I build practical tools, static data systems, AI-assisted workflows, and strange-but-useful web experiments.

Most of my projects start from one simple rule:

> Run it. Measure it. Fix it. Then write down the trap.

I work mainly with C#, .NET, Razor Pages, static JSON, pure frontend applications, and AI-assisted development workflows.

Most of these projects are not made to demonstrate a concept.

They usually begin because I encounter a real problem, cannot find a suitable tool, and decide to build one myself.

```text

than a beautiful idea that never ships.
```
